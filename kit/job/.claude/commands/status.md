แสดงผลบนจอเป็นตาราง ผู้ใช้ไม่ต้องเปิดไฟล์เอง · คำสั่งนี้ห้ามแก้ไฟล์ใด ๆ

1. ถ้า `$ARGUMENTS` ว่าง → รัน `python scripts/ws/job_status.py` แล้ว **แสดงตารางที่ได้ทั้งหมดตามที่พิมพ์** (ห้ามสรุปจนตารางหาย)
   - ตามด้วย 1–2 บรรทัด: "ทำต่อได้เลย" และ "รอใคร" ตามที่สคริปต์บอก · ห้ามเดาสถานะเกินจากผล
2. ถ้า `$ARGUMENTS` = `list` / `all` / ชื่องาน / เลข → งานอื่นอยู่ใน workspace เดียวกัน:
   - หา root ของ workspace (โฟลเดอร์ที่มี `workspace.json` เหนือโฟลเดอร์นี้) แล้วรัน
     `python <root>/tools/workspace.py status --no-fetch [--all] [--pick <เลข>]` หรือ `--job <ชื่อ>`
   - **การดึงสถานะล่าสุดของคนอื่นต้อง `git fetch`** = อ่าน GitHub → ทำตามโหมด (กฎใน kit/CLAUDE.kit.md ข้อ GitHub):
     แบบอ่านเอง-เขียนถาม ทำได้เลย · แบบถามทุกครั้ง ถามก่อน "จะ git fetch origin เพื่อดูสถานะล่าสุดของทุกคน ให้ทำไหม" · แบบคนทำเอง ไม่ fetch แสดงข้อมูลเดิมพร้อมเวลา fetch ล่าสุด
   - แสดงรายการพร้อมเลข แล้วถามข้อเดียว: "พิมพ์เลขเพื่อดูงานนั้นแบบเต็ม" → รันอีกครั้งด้วย `--pick <เลข>` แล้วแสดงตาราง
   - งานของคนอื่น = ดูได้อย่างเดียว · จะทำงานนั้นต้องเปิดแชทที่โฟลเดอร์งานนั้น (1 งาน = 1 แชท)
3. ขั้นที่ขึ้น ⛔ "สถานะไม่ตรง" → บอกไฟล์ที่ขัดกันตามข้อความ แล้วเสนอวิธีแก้พร้อม [แนะนำ] — ห้ามแก้เองในคำสั่งนี้
